# 🛠️ Geomatics & Spatial Analysis Toolkit

Welcome to my personal geomatics engineering and programming toolkit. This repository contains custom scripts and algorithms built for photogrammetry flight planning, spatial data filtering, and image processing.

---

## 📌 Features & Tools
* **Flight Planning Calculations:** Automation for photo overlaps, altitude, and ground sampling distance (GSD).
* **Spatial Data Processing:** Custom Python/MATLAB algorithms for feature detection and image filtering.
